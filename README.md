# Craftsman-Bakery-CBT
제빵기능사

React·TypeScript·Vite 기반 비공식 제빵 학습용 CBT입니다. 서버·로그인·유료 API 없이 브라우저에서 동작합니다.

## 적용 표준

- 최신 표준 확보: `YunSangYeong/electrician-cbt` main `76b990b8720adfa85c22a0a8f699b17094aa357b`, **cbt-site-standard v1.4.0**.
- 앱 코드 출발점: 표준 지정 커밋 `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`의 실제 App/model/styles/설정/테스트/workflow를 재사용·수정했습니다.
- `.agents/skills/cbt-site-standard/` 전체를 복사하고 AGENTS.md에서 연결했습니다. 기존 AGENTS.md는 없었으며 다른 저장소의 앱·배포는 수정하지 않았습니다.
- v1.3의 사용자 전담 배포 정책이 아니라 v1.4의 에이전트 진행·첫 차단 시 중단 정책을 적용합니다.

## 기능

대시보드, 실전 모의시험, 랜덤 문제풀이, 오답 재학습, 북마크, 학습 통계, 문제은행 관리가 있습니다.
실전은 절대 종료 시각·즉시 답안 저장·새로고침 복원·만료 자동 제출·제출 확인·결과/해설을 지원합니다.
랜덤은 즉시 채점·한 순회 ID 중복 방지·연속 정답·세션 정답률을 제공합니다.
두 모드 모두 답안 선택/채점 후 Space로 다음 문제에 이동하며 마지막 시험 문제를 자동 제출하지 않습니다.
입력 컨트롤·메뉴·대화상자·IME·수정키·길게 누르기를 보호합니다. 학습 기준/연도 버전 선택 메뉴는 없습니다.

모바일 고정 메뉴는 100vh/100dvh 제한과 독립 overflow, 자식 높이 보존, overscroll containment를 사용합니다.
작은 세로·가로 화면에서 실제 휠과 터치 입력으로 하단 백업/초기화와 상단 대시보드 접근을 검증합니다.

JSON/CSV 가져오기·양식 다운로드·검색·검증 상태·페이지 목록·중복 제거·로컬 검수 승인·내보내기를 지원합니다.
가져온 문항은 검증 대기이며 로컬 승인 전 학습에 포함하지 않습니다. GitHub 공용 문제은행에 자동 게시하지 않습니다.

## 시험 규칙과 문제은행

공식 Q-Net 요청은 프록시 CONNECT 403으로 차단됐습니다. 최신 공식 시험 규칙·과목·배점·과락·적용 기간 확인은 **미완료**입니다.
현재 60문항·60분·4지선다·60점 합격 표시·과락 미적용은 학습용 가정입니다.
공식 출제 분포를 재현한다고 주장하지 않습니다. 상세는 [시험 규칙](docs/exam-rules.md), 설정은 `src/profile.ts`에 있습니다.

실제 기본 등록: **1,000문항**, 자체 제작 1,000 / 기출 0 / 복원 0.
개념형 80 + 계산 조건 변형 920(20개 문제군 × 46조건)입니다. 통합 과목 1,000개이며 모든 연도·회차는 null입니다.
변형 포함 등록 수를 독립 개념 수로 부풀리지 않습니다. 같은 비례식을 쓰는 문제군도 있고, 92%가 계산 변형이므로 실제 시험 영역을 대표하지 않습니다.

정규화 중복 제거 후 내부 검토 기준 등록 수는 1,000개, 부족분은 0개입니다.
**외부 전문가 검수 완료는 0개이며 공식 출제기준 대조는 미실시**입니다. 따라서 모든 표준 인수 조건을 완료한 것으로 처리하지 않습니다.
AI 일반 지식으로 작성한 원고를 내부 검토했고 계산형은 생성기와 별도 수식으로 검증했습니다.
[문항 검토·단원별 수·이용 조건](docs/question-review.md)을 확인하세요.

## 개발·검증

Node.js 24.19.0 (`.node-version`), npm lockfile을 사용합니다.

```sh
cd /workspace/Craftsman-Bakery-CBT
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

이미 설치된 Chromium을 쓰는 이 환경에서는 다음으로 실행했습니다.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

데이터 재생성: `python3 scripts/generate_bank.py`. 원고와 생성 코드를 보존하며 결과 해시 재현을 검증했습니다.
설치·검증 결과와 배포 상태는 [검증 기록](docs/validation.md)을 참고하세요.

## 저장·백업

저장 키는 `Craftsman-Bakery-CBT:v1`로 전기 CBT와 분리했습니다.
진행 시험·랜덤 세션·오답·북마크·로컬 문항·최근 응답 5,000개·시험 30회를 localStorage에 보관합니다.
통계는 이 보존 범위의 반복 풀이를 포함합니다. 저장 실패는 경고하고 손상 원본을 자동 덮어쓰지 않습니다.
초기화에는 확인창이 있으며 기본 은행은 유지됩니다. JSON 기록 백업 다운로드는 제공하지만 백업 UI 복원은 없습니다.
시크릿/iframe 저장 제한 및 다른 origin의 기록 분리는 브라우저 정책을 따릅니다. 실물 기기와 블로그 iframe 검증은 미실시입니다.
