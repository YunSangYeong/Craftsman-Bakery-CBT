# 제빵 학습 문제은행 작성·검토 기록

## 실제 구성과 이용 조건

기본 은행 `src/data/questions.json`: 자체 제작 1,000문항, 기출 0, 복원 0.
개념형 80문항과 숫자 조건 변형 920문항(20개 문제군 × 46조건)이다.
개념 원고는 `scripts/concepts.tsv`, 결정적 생성기는 `scripts/generate_bank.py`다.
시드 난수를 쓰지 않고 문제군 번호와 조건 번호로 ID·순서·보기 순서를 고정한다.
연도·회차는 전부 null이다. 전기기능사 문항은 포함하지 않았다.

AI 일반 지식으로 이 작업에서 작성했다. 외부 교재나 민간 CBT 사이트에서 문제·해설을 복제하지 않았다.
공식 문제를 읽었다거나 최신 공식 출제기준에 전부 대응한다고 주장하지 않는다.
sourceUrl의 이 저장소 문서는 작성 위치와 검토 기록이지 외부 정답 증빙이 아니다.
자체 제작 원고·JSON·등록 예시의 이용 조건은 CC BY 4.0이다. Craftsman-Bakery-CBT contributors와 저장소 링크를 표시하고 변경을 밝힌다.
소스 코드는 재사용한 MIT 고지를 LICENSE에 보존했다. 제3자 문제의 권리는 별도로 확인해야 한다.

## 검토 범위

- 개념형 80개를 작성하면서 문제·보기·정답·해설의 논리와 표현을 내부 검토했다. 재료·반죽/발효·굽기/품질·위생/안전 각 20개다.
- 법정 보관 온도·살균 시간·식품 표시 의무 등 최신 법령 확인이 필요한 수치를 근거 없이 출제하지 않았다.
- 계산형은 상황·분모·손실 기준·질량/부피/시간 단위·가정을 문제에 명시했다. 실제 제품 권장 배합이나 발효 권장 시간을 뜻하지 않는다.
- 효모 3:1 환산, 전란 수분 75%, 버터 지방 82% 등은 해당 문제에서 주어진 조건이다. 모든 상품의 공통 성분이라고 주장하지 않는다.
- Python Decimal과 ROUND_HALF_UP으로 생성하고 별도 TypeScript/JavaScript 공식으로 920개를 재계산한다. 소수 둘째 자리 반올림·정답 위치·수치적으로 동치인 보기·해설 결과·단위를 검사한다.
- ID와 NFKC 정규화 본문+정렬 보기 지문을 검사한다. 보기 재배치 중복을 포함하여 기본 등록의 기계적 중복은 0개다. 가져온 문항도 같은 경로로 중복 제거하고 pending으로 등록한다.
- 의미상 검토: 개념형은 서로 다른 질문을 사용하지만 관련 개념이 겹친다. 숫자 조건 변형은 같은 문제군의 반복 연습임을 family로 표시한다. 서로 다른 문제군도 같은 비례식을 사용할 수 있다. 1,000개의 독립 개념이나 20개의 독립 수학 공식이라고 세지 않는다.
- 실전 추출은 개념 문항별/계산 family별로 우선 한 자리씩 추출한다. 기본 은행에서는 100개 그룹 중 60개를 뽑아 같은 family가 반복되지 않는다. 사용자 은행에서 그룹이 부족하면 남은 고유 ID로 보충한다.

`reviewed`는 위 내부 검토 및 자동 검증 범위를 뜻한다. 독립된 사람이나 외부 전문가의 검수·공식 출제기준 대조는 **미실시**다.
계산 테스트를 개념·해설의 외부 검증으로 확대 해석하지 않는다. 92%가 숫자 변형이므로 실제 시험의 영역 비중·난이도·문제 유형을 대표하지 않는다.
내부 검토 등록 수 기준 부족분은 0개이며, 외부 전문가 검수 완료 수는 0개다. 공식 기준 대응 은행으로서의 완성도는 미확인이다.

## 재현

```sh
python3 scripts/generate_bank.py
npm test
```

생성 JSON SHA-256: `be4bf62c27feb1e7a12da1337d6c1ba2139667303520c33b715752ceacc531a0`.
두 번 생성하여 해시 일치를 확인했다. 기본 은행 파일에 검증 대기 문항이나 로컬 등록 예시는 넣지 않는다.
