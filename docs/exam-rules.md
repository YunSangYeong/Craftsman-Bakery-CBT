# 시험 규칙 확인 상태

대상: 제빵기능사. 공식 정보 확인 대상으로 Q-Net 종목별 상세 페이지를 요청했다.

- 조사 URL: https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7892
- 조사일: 2026-11-03
- 실제 결과: curl `CONNECT tunnel failed, response 403` (exit 56).
- 응답 본문을 확보하지 못했으므로 URL의 종목 매핑, 최신 과목·문항 형식·시간·배점·합격·과락 조건과 적용 기간을 공식 자료로 확인하지 못했다.
- 민간 사이트 공개 문항을 재배포 가능 자료로 간주하지 않았으며 원문 기출·복원문제는 등록하지 않았다.

앱은 학습용 가정으로 `src/profile.ts`의 다음 구성을 사용한다.

| 항목 | 현재 학습용 구성 | 공식 확인 |
| --- | --- | --- |
| 과목 | 빵류 재료, 제조 및 위생관리 통합 | 미확인 |
| 문제 | 60문항, 4지선다, 단일 정답 | 미확인 |
| 시간 | 60분, 절대 종료 시각 기반 | 미확인 |
| 점수 | 정답 수 / 60 × 100, 동일 배점 | 미확인 |
| 합격 표시 | 원점수 60 이상(36개 이상 정답) | 미확인 |
| 과락 | 미적용 | 미확인 |
| 미응답 | 오답으로 처리 | 앱 정책 |
| 단원별 출제 | 그룹 다양성을 고려한 통합 무작위 | 공식 분포 아님 |

시험 결과 화면은 위 학습용 구성에 따른 결과다. 공식 규칙 확인 완료, 공식 문제 재현, 실제 시험과 동일한 난이도를 주장하지 않는다.
공식 확인 전 현재 프로젝트의 모든 인수 조건을 충족했다고 처리하지 않는다. 향후 공식 원문을 확보하면 해당 원문·적용 기간을 기록하고 설정과 경계 테스트를 대조해야 한다.
앱 상단에 상시 면책 배너를 두지 않고 푸터의 비공식 표시와 문제은행 관리의 출처 상세에서 이 상태를 공개한다.
